# Clock-Oscillator

Realizacija clock oscilatora je fakultetski projekat za predmet Teorija elektičnih kola na Elektrotehničkom fakultetu Univerziteta u Beogradu. Cilj projekta je realizacija analognog električnog kola koje na izlazu daje signal u obliku pravougaonog talasa, čija se frekvencija može menjati pomoću potenciometra.
