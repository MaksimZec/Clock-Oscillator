# Slike simulacija

Ovaj folder sadrži printscreen-ove iz LTspice simulacije.

## Sadržaj
- FFT, Vout, R4(...).png — slike koje prikazuju Furijeovu transformaciju izlaznog signala
- Vout i Vc, R4(200kohm).png — slika koja prikazuje zavisnost izlaznog napona od napona na kondenzatoru
- Vout, R4(x).png — slike koje prikazuju izlazni signal za različite otpornosti otpornika R4
- Kolo.png — šema kola

## Cilj
Cilj je prikazati zavisnost izlaznog napona na Vout pinu od otpornosti R4, koja predstavlja operacioni pojačavač. Grafički se prikazuje promena perioda izlaznog signala pri promeni otpornosti, kao i promena frekvencijskog spektra dobijenog Furijeovom transformacijom signala.
