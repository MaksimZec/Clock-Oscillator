#Slike simulacija

Ovaj folder sadrži printscreen-ove iz LTspice simulacije.

##Sadržaj
- FFT,Vout,R4(...).png — slike, koje prikazuju Furijeovu transformaciju izlaznog signala
- Vout i Vc, R4(200kohm).png — sliku, koja prikazuje zavisnost izlaznog napona od napona na kondenzatoru
- Vout, R4(x).png — slike, koje prikazuju izlazni signal za različite otpornosi otpornika R4
- Kolo.png — šema kola

##Cilj
Cilj je da se datim ilustracija prikažu zavisnot izlaznog napona na Vout pinu od otpornosti R4,
koja pretstavlja operacioni pojačavča. Grafički prikazujući promenu perioda izlaznog signala pri promeni otpornosi 
tako i grafički prikazujuću promenu frekvencijiskog sprektra dobijenog Furijeovom transformacijom signala.
