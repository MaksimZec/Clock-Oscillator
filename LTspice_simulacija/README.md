# LTspice_simulacija

This folder contains LTspice simulation files for the Clock-Oscillator project.

## Contents
- *.asc / *.asy — LTspice schematic files
- *.net / *.raw — simulation outputs (if any)
- Notes.md — any experiment notes (optional)

## How to run
1. Open the `.asc` schematic in LTspice (http://www.analog.com/ltspice).
2. Run the simulation (Run button or Simulate → Run).
3. View waveforms in the waveform viewer. Save raw data if needed.

## Purpose
Briefly state what these simulations show (e.g., oscillator startup, frequency vs. load, supply sensitivity).

## Tips
- Use the correct LTspice component models (include .lib/.subckt as needed).
- If schematics reference local model files, ensure relative paths are correct.
